# Topic Reviewer - 选题审核

## 运行契约（单独跑 / 被调度器调用都走这一套）

- **输入**：选题清单，来自 topic-generator 的对话输出，或由用户直接给出
  （底层字段来自 topic-collector：`title`/`source`/`url`/`published_at`/`heat`/`summary`/`tags`/`lang`）
- **产物**：**不落盘** —— 通过 / 不通过结论 + 评分明细输出到对话，由调用方决定如何使用
- **幂等**：无副作用，可重复运行
- **前置**：无配置项。**时效只依据 `published_at` 字段**，不凭内容里「最近」「近日」等模糊表述推断

## 输入与字段依赖

选题由 topic-generator 产出，底层数据来自 topic-collector 的统一字段：
`title` / `source` / `url` / `published_at` / `heat` / `summary` / `tags` / `lang`

时效判定**只依据 `published_at`**，不要凭内容中的"最近""近日"等模糊表述推断：

| published_at | 处理方式 |
|--------------|----------|
| 有确切时间 | 据此判断是否超过 72 小时 |
| N/A | 无法判定，标注「时间待确认」并在时效项降一档，不直接否决 |
| 明显矛盾 | 与其他字段冲突时按存疑处理，要求补证 |

## 审核流程

1. **接收选题**（来自topic-generator或用户输入）
2. **逐项检查**：按审核清单打分
3. **输出结论**：通过/不通过 + 理由

## 受众口径（本节只指路，不定义内容）

**执行审核前，先 Read `gzh-write-enhanced/resources/author_voice.md`，取其「## 受众」「## 文章赛道」两段作为本技能的口径。**

> ⚠️ 本节**故意不写出受众和赛道的具体内容**。理由：改人设时只改 `author_voice.md`，
> 复制在这里的旧口径不会跟着变，选题会静默按已作废的受众打分。
>
> 选题阶段就要按受众卡，否则后面写作会为了迁就选题而偏离人设。

## 审核清单

### 必过项（一票否决）

| 检查项 | 不通过标准 |
|--------|------------|
| 热度 | 讨论量<100或无增长趋势 |
| 相关性 | 与AI/编程/效率无关 |
| 时效性 | 超过72小时的旧闻 |
| 可写性 | 没有可操作的内容输出 |
| **受众匹配** | 只适合研究者 / 泛大众，程序员与架构师用不上；或属大模型训练与底层研发 |

### 评分项（满分100）

| 维度 | 权重 | 评分标准 |
|------|------|----------|
| 独特角度 | 25% | 有无别人没写过的切入点 |
| 用户价值 | 20% | 读者能获得什么 |
| 国内适配 | 15% | 国内用户是否关注 |
| 标题吸引力 | 15% | 是否想点进去看 |
| **受众匹配** | **15%** | 程序员 / 一人公司 / 技术总监 / CTO 是否当天就能用上 |
| 写作难度 | 10% | 能否快速高质量完成 |

**通过线：70分**

## 不通过的常见原因

1. **热度不够高**
   - 表现：源头讨论量低，无传播趋势
   - 建议：等热度起来再写，或换热点

2. **没有独特角度**
   - 表现：已有大量类似文章
   - 建议：找差异化切入点，或放弃

3. **不符合国内用户关注**
   - 表现：纯海外事件，无本土关联
   - 建议：找国内用户共鸣点，或翻译+本土化

4. **纯蹭热点无干货**
   - 表现：只是转述新闻，无增量信息
   - 建议：加入实操/测评/深度分析

5. **写作成本过高**
   - 表现：需要大量调研或技术门槛高
   - 建议：简化范围或分拆系列

## 输出格式

```markdown
## 选题审核结果

**选题**：[标题]

**结论**：✅ 通过 / ❌ 不通过

**评分**：XX/100

| 维度 | 得分 | 说明 |
|------|------|------|
| 独特角度 | /25 | |
| 用户价值 | /20 | |
| 国内适配 | /15 | |
| 标题吸引力 | /15 | |
| 受众匹配 | /15 | |
| 写作难度 | /10 | |

> ⚠️ 上表的维度与满分**必须与「评分项（满分100）」那张表逐行一致**，不得在此另立一套。
> 2026-10-09 修复：旧模板是 5 维度 /30 /25 /20 /15 /10，与评分表（6 维度，含受众匹配 15%）
> 完全对不上，按它输出会漏评受众匹配且分数分母全错。
> **改权重的唯一位置是上文「评分项」表**，改完记得让本模板同步。

**审核意见**
- 优点：...
- 问题：...
- 建议：...

**修改方向**（如不通过）
1. ...
2. ...
```

## 快速判断

没时间细评时，问自己：
1. 今天不写会后悔吗？
2. 写完能获得什么反馈？
3. 一句话能说清为什么值得写吗？

3个都是"是" = 直接写

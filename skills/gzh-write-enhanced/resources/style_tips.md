# 口语化风格技巧库

> **版本**：v1.0
> **溯源说明**：口语化词组的设计思路，参考了业内通行的 AI 文本特征检测方法与中文自媒体写作经验，结合实战场景整理而成
> **用途**：写作时自然植入，增加活人感

---

## 1. 口语化转场词

### 推荐使用

- "说真的"、"坦白讲"、"我是真的觉得"
- "怎么说呢"、"其实吧"、"你想啊"
- "顺着上面的，再聊两句"
- "回到这个话题"
- "这块需要注意一下"
- "不瞒你说"、"说实话"
- "我是真没想到"
- "说个有意思的"

### ❌ 避免使用

- "接下来让我们讨论..."
- "值得注意的是..."
- "首先...其次...最后..."
- "在深入探讨之前..."

## 4. 情绪表达

### 推荐使用（按场景选择，不要只用一种）

**好奇/研究型**（最适合AI专家人设）
- "我琢磨了一下"
- "我好奇地试了试"
- "这块我研究了下"
- "说真的我去查了一下"

**怀疑/质疑型**（有主见，不盲信）
- "真的假的？"
- "我一开始是不信的"
- "这个说法我打个问号"
- "有点夸张了吧"

**顿悟/原来如此型**（有认知差，不是被震撼）
- "哦，关键在这"
- "一下就通了"
- "原来绕了个弯"

**无奈/好笑型**（接地气，有情绪）
- "你说气人不气人"
- "笑死"
- "这操作给我看乐了"
- "给我整不会了"（偶尔用，别每篇用）

**务实惊喜型**（专家认可工具，但不是"震撼"）
- "还真行"
- "有点东西"
- "这玩意能用"
- "比我想象的靠谱"

**共鸣型**（拉近距离）
- "说不就是我当年"
- "说到点上了"
- "谁还没踩过这坑"

**紧迫感型**（搞钱博主的特色）
- "这波不跟上就亏了"
- "再不动手就晚了"

### ❌ 避免使用

- "我感到非常震撼" → 太书面
- "我当时就愣住了" → 用太多，且不适合专家人设，偶尔可用但别当标配
- "惊呆了" → 太像营销号
- "太震撼了" → 同上

### 使用原则

- 每篇文章最多用 **1-2种** 情绪表达，不要堆砌
- 根据内容选情绪：测评用"质疑+务实惊喜"，经验分享用"共鸣+顿悟"
- "愣住"不是禁用，是**慎用**——一个AI专家不该天天被新工具愣住

## 8. 句式断裂技巧

### 制造停顿和重量

- "黑暗森林。"
- "大时代啊。"
- "时间。流逝的本身。"

## 9. 开头必杀技

### 叙事启动

```
事情是这样的。
我最近在 Twitter 上刷到一个有意思的事...
```

### 反直觉事实

```
说出来你可能不信，腾讯云最近的价格...
承认吧，你的 XX 正在变得一文不值。
```

### 热点破题

```
这两天地铁上都在聊 AI 程序员。
Seedance 2.0 的火，已经烧了好几天了。
```

### 好奇驱动

```
我在 Twitter 上刷到一个有意思的事。
有个问题一直困扰着我...
```

## 11. 升番逻辑（逐一展示）

当涉及多个产品/模型/案例的对比或测试时，不要一次性罗列结论，而是逐一展示，每个都带一句吐槽或点评。

**升番结构**：
1. 先展示基础功能（让大家觉得还行）
2. 再放进阶用法（让大家觉得有点意思）
3. 最后放出骚操作（让大家觉得"卧槽还能这么玩"）

**排列顺序**：最弱的放前面，最炸的留到最后

## 12. 人物画像法

从一个数据点出发，用极短的篇幅想象背后那个具体的人的完整人生：

```
触发点数据（"1000个已付款"）
→ 快速代入（"他可能是一个..."）
→ 多维堆砌（城市→职位→生活→心理→具体行为）
→ 情感锚定（为什么这样做）
→ 细节具象化（十几平米出租屋、拼好饭）
```

---

## 13. 对立面理解

在讲核心观点前，先站在对方的角度把处境具体化：

```
你不是程序员，不需要写代码。
你不是做内容的，不需要天天写文章。
你就是一个普通的上班族。
我非常理解这种感觉。
但是...
```

## 14. 禁用词/标点提醒

### 禁用词

- ❌ "说白了" → ✅ "坦白讲"
- ❌ "意味着什么" → ✅ "所以呢"
- ❌ "本质上" → ✅ "说到底"
- ❌ "换句话说" → ✅ "也就是说"

### 禁用标点

- ❌ 冒号 `：` → ✅ 用逗号替代
- ❌ 破折号 `——` → ✅ 用逗号替代
- ❌ 双引号 `""` → ✅ 用「」替代

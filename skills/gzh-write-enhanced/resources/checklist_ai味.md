# AI 味四层自检清单

> **版本**：v1.0
> **溯源说明**：四层结构的设计思路，参考了业内通行的 AI 文本特征检测方法与中文自媒体写作经验，在此基础上重新组织并扩展为 L1–L4 四层体系
> **用途**：文章生成后自动调用，确保没有AI味
> **强制要求**：L1/L2/L3/L4 必须全部通过才能输出终稿

---

## L1 硬性规则检查（零容忍）

### L1-1 禁用词扫描

| 命中词 | 替换方案 |
|--------|---------|
| "说白了" | "坦白讲"、"说真的" |
| "意味着什么" | "所以呢"、"那结果呢" |
| "本质上" | "说到底"、"归根结底" |
| "换句话说" | "也就是说"、"你想啊" |
| "不可否认" | 直接删掉，换成正面陈述 |
| "综上所述" | 用具体回扣句替代 |
| "首先...其次...最后" | 用"再来"、"还有"等自然转场 |
| "值得注意的是" | 直接删掉 |
| "让我们来看看" | "我带你看看"、"说个有意思的" |
| "不难发现" | 直接删掉 |
| "可能" | 删除或改为"大概率" |
| "我觉得" | 改为"事实是"、"真相是" |
| 空泛工具名："AI工具"、"某个模型" | 必须写具体名字：Claude Code、Qwen3.6、DeepSeek |

### L1-2 禁用标点

| 禁用标点 | 替代方案 |
|----------|---------|
| 冒号 `：` | 用逗号替代 |
| 破折号 `——` | 用逗号或句号替代 |
| 双引号 `""` | 用「」替代 |

### L1-3 结构性套话

- ❌ "在这个数字化时代..."
- ❌ "随着AI技术的不断发展..."
- ❌ "在当今AI快速发展的时代..."
- ❌ 连续3个以上 bullet point → 改成散文叙述
- ❌ 大段加粗（超过2行）

### L1-5 加粗占比检查

- [ ] 加粗字符总数约等于全文字符数的5%（粗估：全文约3000字，加粗应≤150字）
- [ ] 判断标准：和文章相关的名词、术语才值得加粗（如工具名、关键概念、技术名词）
- [ ] 不加粗：观点句、情绪表达、口语化金句

### L1-4 工具名检查

- [ ] 所有AI工具/产品都使用具体名称
- [ ] 无"AI工具"、"某个模型"、"相关技术"等空泛表述

**通过标准**：L1-1至L1-4 零命中

**修复方式**：逐个替换，用推荐口语化词组中的表达替代

---

## L2 风格一致性检查

### L2-1 开头检查

- [ ] 是否从具体事件/场景切入？（不是"近年来AI发展..."）
- [ ] 第一句话是否有冲击力？5秒内抓住读者？
- [ ] 有没有教科书式开头？（"随着..."、"在当今..."）

### L2-2 节奏检查

- [ ] 长短句交替？（连续3句以上句式长度相近 = 节奏呆板）
- [ ] 一句话独立成段（句式断裂）≥3处？
- [ ] 有没有疑问句作为"刹车和转向"？
- [ ] 有没有"扣主线句"拉回偏离内容？

### L2-3 口语化检查

- [ ] 口语化转场自然穿插（全篇 2–4 处即可），不机械堆叠？（详见 style_tips.md）
- [ ] 若转场词出现 ≥6 处且分布均匀机械，判为 AI 味，打回
- [ ] 有没有自嘲或承认不足？
- [ ] 情绪表达是体感记忆而非知识描述？

### L2-4 标点禁令二次确认

- [ ] 全文无冒号、破折号、双引号
- [ ] （AI容易在修改过程中重新引入这些标点）

**通过标准**：L2-1全部通过，L2-2至少3/4通过，L2-3至少3/4通过，L2-4通过

**修复方式**：逐段检查，对不符合的段落进行改写

---

## L3 内容质量检查

### L3-1 观点支撑

- [ ] 每个核心观点都有具体案例/数据/场景支撑？
- [ ] 没有空泛论断？

### L3-2 知识输出方式

- [ ] 知识点是"顺手掏出来"而非"下面科普一下"？
- [ ] 引用是否自然融入论述？

### L3-3 剥洋葱结构检查

- [ ] 开篇：反直觉钩子？（震撼现象/数据）
- [ ] 第一层：现象拆解，还原惊人细节
- [ ] 第二层：认知翻转，反常识洞见
- [ ] 第三层：底层逻辑，深度剖析生产关系/杠杆效率
- [ ] 第四层：商业实验，3个具体"搞钱"切口
- [ ] 结尾：冷峻号召？（极其精简，不煽情）

### L3-4 对立面理解

- [ ] 是否先承认读者处境，再给不同视角？
- [ ] 有没有"我理解你，但是..."的结构？

**通过标准**：L3-1和L3-2必须全部通过，L3-3至L3-4中至少通过相关项

**修复方式**：补充案例、改写知识输出方式

---

## L4 活人感终审（最重要）

**核心问题**："这是作者在跟我聊一件打动他的事，还是 AI 在输出信息？"

### L4-1 温度感

- [ ] 文中的情绪表达是体感记忆（"我当时就愣住了"）而非知识描述（"我感到震撼"）？
- [ ] 如果有人物描写，是否能让人"感觉到他的体温"？

### L4-2 独特性

- [ ] 是否有"只有作者才会写"的角度？
- [ ] 换个AI博主能写出差不多的吗？

### L4-3 姿态

- [ ] 是"有见识的实战派在分享"而非"导师在教学生"？
- [ ] 有没有不自觉的居高临下感？

### L4-4 心流

- [ ] 从头读到尾有没有注意力断点？
- [ ] 如果有，哪个地方需要回头理解逻辑？

### L4-5 反向扫描（AI 味特征逐句排查，零命中才过）

- [ ] **标语化 / 工整对仗**：如「X 最危险」「Y 才是答案」「指令越像契约，产出越可控」这类抽象拔高、对仗口号句，改回大白话或补具体场景
- [ ] **概念造词**：如「伪正确」「范式转移」「数字化宪法」等生造 / 过度抽象词，除非有具体上下文，否则改回日常表达
- [ ] **宏大抽象开场**：如「开发的范式在悄悄转移」「在这个时代……」，必须落地到具体事件 / 场景
- [ ] **写作残留标记**：终稿不得出现「金句放这」「分水岭就一句话」「降温一下」等模板指令痕迹，出现即打回重清
- [ ] **结尾口号割裂**：「想，全是问题。干，就对了。」类口号若强塞、与正文语感割裂，删或自然化

**通过标准**：L4-1到L4-5整体感觉"这像是真人写的"，且 L4-5 零命中

**修复方式**：把"AI味重"的段落找出来，想象作者本人会怎么说，然后用更口语、更私人、更不完美的方式重写

## 自检执行流程

1. **生成完整正文**
2. **逐层扫描**（L1 → L2 → L3 → L4）
3. **标记问题**（每个L层单独列出）
4. **自动修复**（L1/L2可自动修复，L3/L4需人工改写）
5. **二次确认**（确保修复后没有引入新问题）
6. **输出终稿**（四层全部通过后）

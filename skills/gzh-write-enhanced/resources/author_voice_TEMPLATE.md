# 作者叙事口吻模板（用前自填）

> **这是干什么的**：ABC 三版可以各有结构分工，但**叙事口吻必须统一为作者本人**。
> 最容易翻车的场景：结构、禁用词、加粗比例全部达标，读起来却「像科技媒体专栏，
> 不像本人在跟读者聊天」。这份模板帮你把自己的口吻提炼成文，交给 AI 执行时才不会走样。
>
> **用前配置**：复制本文件为 `author_voice.md`，抽你自己的 3~5 篇代表作逐句对比，把下面的
> 维度填成你自己的例句，删掉不适用的维度、加上你独有的维度。写完后再把文件名里的 TEMPLATE 去掉。

## 一、提炼方法（一次性做 30 分钟）

1. 从你已发布的文章里选 4~5 篇**不同类型**的代表作（热点评论 / 个人经历方法论 / 盘点清单各来一篇）。
2. 只读开头 800 字和结尾 300 字，逐句问：这句话换成任何一个作者都能写吗？**能，就说明不是你的签名句**；只有你能这么写的，抄下来。
3. 把抄下来的句子按下面的维度归类，每个维度留 2~3 个真实例句。
4. 交稿自检时，AI 拿成稿对照这些例句逐条核对。

## 二、常见签名维度（示例，按你自己的文章提炼替换）

| 维度 | 说明 | 你的例句（自填） |
|------|------|------------------|
| 体感开场 | 钩子之后先写「我」看到这条信息时的身体反应，再展开事实 | （例：我盯着看了十秒，没有振奋，有点愣） |
| 剥皮短句 | 「不是 A，是 B」式一句话一段的短促纠正句 | （例：不是价格变了，是干活的人换了） |
| 招呼式反问 | 把读者拽进对话的口头反问，每篇 3~5 处 | （例：你想啊 / 说个有意思的） |
| 案例三要素 | 案例 = 人 + 具体结果 + 一个出格细节，缺一不可 | （例：陈总写了一整页 A4 纸） |
| 敢抬杠 | 对引用的信源敢直接说「我觉得他说得不对」，不能通篇顺从 | （自填） |
| 背景嵌叙事 | 个人背景嵌进故事里讲，不用简历腔自我介绍 | （例：从我还在车间三班倒的时候说起） |
| 土比喻 | 每个大节至少一个生活化比喻，好到能直接当小标题 | （例：无证司机） |
| （你的独有维度） | | （自填） |

## 三、交稿前口吻自检（7 问，不过 = 返工）

1. 钩子之后，「我」登场了吗？有自己的体感反应吗？
2. 有没有至少 2 句「不是 A，是 B」式的剥皮短句？
3. 招呼式反问够 3 处吗？
4. 每个案例都有人、有结果、有出格细节吗？
5. 对外部信源抬过杠吗？（通篇顺从所有信源 = 最不像本人）
6. 段落够短促吗？（长段数据连排 = 专栏腔，拆句）
7. 每个大节有土比喻吗？

## 四、给 AI 的执行指令（写入你的调度 skill）

> 写作前必须先读 `resources/author_voice.md` 并严格执行：三版结构可以各有分工，
> 但叙事口吻必须统一为作者本人；交稿前逐条过第三节自检，不过 = 返工。

# 公众号备选标题库

> **版本**：v1.0
> **用途**：生成文章后，自动生成40个备选标题，按8类风格各5个
> **要求**：标题必须放在文章正文最开头

## 标题生成要求

1. **40个标题必须全部生成**，放在文章正文最开头
2. **每类5个**，严格按照分类生成
3. **符合作者风格**：
   - 断言式表达
   - 反直觉冲击力
   - 具体数字
   - 口语化
4. **避免标题党**：
   - 不过度夸张
   - 不虚假承诺
   - 与文章内容匹配

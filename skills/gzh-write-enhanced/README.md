# gzh-write-enhanced

**把「能看」的 AI 初稿，改写成「像人写的」成稿。**

> 我写了 300 多篇公众号，最后发现最难的不是写出来，是让 AI 写出来的东西不像 AI 写的。

## 先看效果

同一段内容，AI 直接写 vs 走完这个 skill 的四层自检：

### ❌ 改前（典型 AI 味）

> 随着人工智能技术的不断发展，AI 写作工具正在为内容创作者带来前所未有的机遇。不难发现，传统的写作方式正在被深刻重塑。综上所述，掌握 AI 写作技能，将成为每一个内容创作者的必修课。本质上，这是一场关于效率的革命。

**问题**：套话开头、禁用词三连（不难发现 / 综上所述 / 本质上）、没有具体信息、读完记不住任何一句。

### ✅ 改后

> 说实话，我第一次用 AI 写完一篇文章，自己读了两段就关掉了。
>
> 不是写得不好，是写得**太好了**——好到挑不出毛病，也好到一句都记不住。
>
> 每个字都对，连起来像说明书。这种文章，读者划两下就过去了。

**改了什么**：反直觉钩子开头、口语化转场、承认不足、短段落、具体场景。

完整对比见 [`examples/before_after.md`](examples/before_after.md)。

## 它到底做了什么

### 1. 三版并行，而不是一版定生死

| 版本 | 解决什么 | 读者反应 |
|------|----------|----------|
| **A 版 · 反直觉洞察** | 剥洋葱四层：现象拆解 → 认知翻转 → 底层逻辑 → 商业实验 | **转发** |
| **B 版 · 观点分析** | 温度感 + 降温段，观点推进 | 读完 |
| **C 版 · 实操教程** | 体验式叙事，先亮结果再拆步骤 | **收藏** |

三版写完，把 **A + C 合并**成终稿——既有观点冲击力，又有干货密度。

### 2. 四层 AI 味自检（这是核心）

```
L1 硬性规则  →  禁用词 / 禁用标点 / 加粗占比，零容忍
L2 风格一致性 →  开头冲击力、节奏、口语化密度
L3 内容质量  →  每个观点有没有案例支撑、剥洋葱结构是否完整
L4 活人感终审 →  「这是人在跟我聊一件打动他的事，还是 AI 在输出信息？」
```

**四层全部通过才算达标，任何一层不过都要返工。**

L1/L2 的问题 AI 可以自动修（换词、改标点）；L3/L4 必须人工改写——这也是它有效的原因：**它逼 AI 承认哪些地方它做不到**。

### 3. 40 个备选标题，8 类各 5 个

反直觉冲击 / 利益承诺 / 对立冲突 / 悬念揭秘 / 数字结果 / 场景故事 / 热点绑定 / 负面焦虑。

支持 [WorkBuddy](https://www.workbuddy.cn) / Claude Code / 其他 Agent Skills 规范的平台：

```bash
# WorkBuddy
git clone https://github.com/xiaohuAI319/gzh-write-enhanced.git ~/.workbuddy/skills/gzh-write-enhanced

# Claude Code
git clone https://github.com/xiaohuAI319/gzh-write-enhanced.git ~/.claude/skills/gzh-write-enhanced
```

装完直接说：「用 gzh-write-enhanced 写一篇关于 XXX 的公众号文章」。

### 方式二：手动复制

把整个文件夹拖进你的 skills 目录即可。**不需要安装任何依赖**——这个 skill 是纯 Markdown，没有一行代码。

### 方式三：不装，直接当提示词用

打开 `resources/` 里的模板，把内容复制给任何 AI 对话工具，一样能用。

## 使用前必做的一步：填人设

三个模板里都有 `{{作者人设}}`，**必须先替换成你自己的背景**。这一步不能跳过。

人设决定了文章的语气和可信度来源——AI 不知道你是谁，就没法写出「只有你会说的话」。

```
{{作者人设}} = 你的年代 / 专业背景 / 职业身份 / 专注领域 / 面向的读者
```

仓库里的默认值是开源作者本人的配置（70 后，计算机科班，AI 讲师，专注「AI 编程 + 搞钱」），仅供参考，换成你自己的。

## 三条最狠的规则（先记住这三条就能用起来）

1. **禁用标点**：不许用冒号 `：`、破折号 `——`、双引号 `""`。改用逗号和「」。
   —— 光这一条，AI 味就能去掉三成。

2. **加粗不超过 5%**：全文加粗字数占比 ≤ 5%，每篇 5–8 处封顶。
   —— 判断标准：**这句话删掉，文章就缺一块的，才值得加粗。**

3. **情绪要体感记忆，不要知识描述**：
   ❌「我感到非常震撼」→ ✅「我盯着屏幕看了半天，憋出四个字」

完整规则见 [`resources/checklist_ai味.md`](resources/checklist_ai味.md)。
